summary: Built-in help of FileAssert, the tool that checks files against a YAML test suite.
---
{{tool}} checks files against a test suite written in YAML: how many files
match a pattern, how large they are, their text, and the content of XML,
HTML, JSON, YAML, PDF, and zip files.

Every operation is an option. The only command is `{{tool}} help`, which
must be the first argument and takes topic names, such as
`{{tool}} help configuration`.
